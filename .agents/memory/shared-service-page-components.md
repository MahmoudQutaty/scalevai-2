---
name: Shared service-page components
description: Reuse repeated UI across ScaleVAI service pages instead of rebuilding it per page.
---

For ScaleVAI service pages, check existing shared components before creating a new section. Prefer data-driven components with explicit layout variants when pages need different presentations of the same pattern.

**Why:** the user wants reusable components they can use on other pages instead of building repeated UI from scratch.

**How to apply:** compare similar sections across pages, reuse or extend the shared component, and keep page-specific copy and visuals in data or explicit variants.
